# md-simple-editor
mdファイルの記述法を簡単に学ぶことができるエディターです。

## 使い方

`index.html` をブラウザで開くだけで使えます（ダブルクリックで `file://` として開いても動作します）。
サーバーやビルド、外部ライブラリは不要です（HTML / CSS / バニラ JavaScript のみ）。

## 主な機能

- **書き込み画面とプレビュー画面**：入力すると即座にプレビューへ反映（表示は「書く / 両方 / 見る」で切替）
- **ツールバー**：見出し・太字・斜体・打ち消し線・コード・リスト・チェックリスト・リンク・画像・表・引用・コードブロック・水平線を挿入
- **マークダウン辞書**：記法ごとに「書き方」と「表示結果」を並べて表示。検索・カテゴリ移動・挿入・コピーが可能
- **サンプル画像**：`images/` に同梱したダミー画像をワンクリックで挿入し、画像表示を試せる
- **練習問題**：プレビューの内容を自動判定してクリア状況を表示
- **よくある間違いのヒント**：`(文字)[URL]` の逆転、`#見出し` のスペース忘れ、全角記号・全角スペースなどを指摘
- **ファイル操作**：`.md` のアップロード（ボタン / ドラッグ＆ドロップ）、ダウンロード、HTML 出力
- ヘッダーの ☀️ / 🌙 ボタンでダークモード（既定）とライトモードを切り替え（選択は保存されます）
- 入力内容は自動保存（ブラウザの localStorage が使える場合）
- ショートカット：`Ctrl+B` 太字 / `Ctrl+I` 斜体 / `Ctrl+K` リンク / `Ctrl+S` ダウンロード / `Tab`・`Shift+Tab` 字下げ

## 対応している記法

見出し（`#` / 下線記法）、段落・改行、太字、斜体、打ち消し線、ハイライト（`==`）、
番号なし・番号付き・入れ子・チェックリスト、表（列揃え）、リンク（インライン / 参照 / 自動リンク / ページ内）、
画像、水平線、引用（入れ子 / GitHub 形式のアラート）、インラインコード、コードブロック、脚注、
エスケープ、一部の HTML タグ（`<kbd>` `<sup>` `<sub>` `<br>` など）、コメント、絵文字（`:smile:` など）

## ファイル構成

```
index.html        画面
css/style.css     スタイル（ダーク / ライト切り替え。既定はダーク）
js/markdown.js    マークダウン → HTML 変換器（自作・依存なし）
js/data.js        辞書・サンプル画像・練習問題・初期テキスト
js/app.js         画面の動作
images/           サンプル用のダミー画像（SVG）
```
